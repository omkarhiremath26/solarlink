# Neighborhood Energy Sharing Platform

A peer-to-peer energy sharing platform that allows households to share excess solar electricity with nearby homes using a credit-based system.

## Features

- 🔐 **Secure Authentication** - User registration and login with password hashing
- 📊 **Energy Dashboard** - Track energy production, consumption, and credit balance
- 📝 **Energy Input Form** - Enter production and consumption data
- 💹 **Energy Marketplace** - View houses with excess or deficit energy
- 🔄 **Energy Transfer** - Simulate energy transfers between users
- 📜 **Transaction History** - View all energy sharing transactions
- 🎨 **Modern UI** - Clean renewable energy theme with responsive design

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5
- **Backend**: Python, Flask Framework
- **Database**: SQLite with SQLAlchemy ORM
- **Authentication**: Flask-Login, Werkzeug
